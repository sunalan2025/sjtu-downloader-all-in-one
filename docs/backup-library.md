# 资源库与课程备份

实现日期：2026-10-25。本次提供任务持久化、增量补齐、课程订阅、统一资源清单的首版闭环。

## 使用

1. 登录账号，在设置中选择保存模式与目录。顶栏打开「资源库」。
2. 添加订阅，读取可访问课程，选择课件、视频及视角，设置检查间隔（5 分钟至 7 天）。默认不自动下载。
3. 「检查更新」更新清单；「检查并补齐」扫描并提交缺失或新版本资源。开启「自动下载」后，定时检查也会补齐。
4. 订阅固定保存时的目标；「调整订阅」可以重新应用当前保存设置。暂停或移除订阅不会删除已有文件。
5. 「资源文件」支持搜索和本机文件定位；「检查本机副本」检查存在性和大小。
6. 退出时选「保存任务并退出」，重开后在「任务恢复」继续；顶栏角标显示待恢复数量。明确取消的任务不会自动复活。单次批量恢复最多 500 项。

## 当前覆盖范围

| 来源/操作 | 支持范围与限制 |
| --- | --- |
| Canvas 订阅 | 可访问的文件列表、模块/大纲中可解析文件、课堂录播；文件版本使用文件 ID、修改时间、大小、名称 |
| 好大学在线订阅 | 章节资源；下载解析时确认视频/课件类型。源站未提供可靠修改时间，同 ID 内部替换可能无法识别 |
| 旁听订阅 | 已获授权课程的视频与教师/PPT 视角；同 ID 内部替换可能无法识别 |
| 普通本机下载恢复 | 保存实际文件与 `.part` 路径；使用 HTTP ETag/Last-Modified 或 Canvas 元数据校验。服务端不支持 Range、版本不可验证或已变化时重新下载 |
| HLS 恢复 | 重新下载合并，不持久化切片级完成状态；远端代传沿用现有引擎能力限制 |
| 直传云盘恢复 | 重新上传；不复用进程内的上传会话 |
| 远端恢复 | 先查询原任务，仍在运行或已完成则接管状态；无法确认状态时不重复提交。需原服务器和凭据可用 |
| 特殊导出 | 作业归档、字幕、PPT/PDF 导出继续从原课程页发起，尚未纳入订阅和跨重启恢复 |
| 旧资源与云盘管理器 | 不扫描导入旧目录；云盘管理器独立上传/下载流程未纳入此清单 |

订阅依赖应用运行、网络及原账号有效登录，不创建系统计划任务。登录失效会显示错误并按间隔重试，不在后台弹出登录窗口。课程资源范围受原平台授权限制。

本机检查只比较文件存在性和大小，**不是内容哈希校验**；无法检测同大小损坏。云盘与远端副本记录代表收到过完成回执，未主动验证之后是否被删除。源站未提供可靠版本的资源不能保证发现所有内部内容变化。新版本使用带版本后缀的文件名，不自动删除旧版。

## 数据与安全

- 主进程单写 `app.getPath('userData')/resource-catalog-v1.json`；任务先持久化再进入调度器，写盘失败时回滚本批入队记录。
- 临时文件写入、fsync、重命名替换；进度合并限频保存。退出前再次检查点保存，异常退出按已保存任务恢复。
- 账号用学工号摘要隔离；恢复、扫描返回与提交前检查账号，IPC 仅接受主窗口主 frame。
- 清单只保存白名单来源字段，不保存登录 Cookie、云盘 token、Worker token、课堂短期 token。无法重新解析的下载地址使用系统 safeStorage 加密；加密不可用时明确标记不可跨重启恢复。
- 恢复前验证文件位置位于原保存根目录；下载器发送 Range/If-Range 并校验返回偏移。恢复所需 `.part` 与已登记文件受清理保护；清单损坏时保留原文件并暂停自动清理。
- 资源与恢复列表每页 50 项；本机文件检查并发 8，补齐按 100 项入队；后台一次只检查一门订阅，避免叠加扫描。JSON 清单保留资源与版本历史，尚无自动归档策略。

研究依据：[Electron app 生命周期](https://www.electronjs.org/docs/latest/api/app)指出 Windows 系统退出不保证触发常规退出事件，因此不能只在退出时保存；[Canvas Files API](https://developerdocs.instructure.com/services/canvas/resources/files)提供文件标识、大小及更新时间，供文件版本比较使用。
