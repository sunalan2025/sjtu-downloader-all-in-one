# 文件管理交互与分栏修复

## 已确认的交互

- 网格和列表：单击选中，双击打开文件夹或文件详情。
- 分栏：单击文件夹进入下一级；单击文件选中并显示详情。
- Ctrl/Cmd 增减选择，Shift 按当前展示顺序连续选择；从空白处拖动框选，支持滚动选择。
- 保留复选框，提供 Ctrl/Cmd+A、Escape、方向键、空格和 Enter。
- 课程资源依平台能力提供详情、下载和转存；云盘自有文件保留复制、移动、重命名和删除等操作。

## 实现与根因

共用 `features/file-manager/SelectionSurface.tsx` 和纯选择算法承载鼠标、键盘与框选行为，课程与云盘通过适配层连接自己的数据。进入另一目录时清空原目录选择，切换视图时保留同一目录的选择。

Canvas PPT 讲义原先每一讲共用整门课程的选择开关。现在每讲有独立选择状态和任务 ID，分类统计支持部分选中；批量提交只传选中的讲次，单项下载复用已有单讲接口。修改某个文件的选择时会清除相应分类的全选意图，避免界面取消选择后实际仍提交全部文件。

云盘父级分栏此前使用完整列表行，日期和大小占据名称空间。现在各列采用紧凑行，只保留复选框、课程页同款蓝色文件夹图标、名称及方向箭头；当前导航项高亮，标题可返回对应父目录，整行可导航。父级列也支持文件选择，操作路径与当前浏览路径分别保存，防止父级文件操作错误地作用于子目录。

## 验证

- 合成数据浏览器交互：课程和云盘三种视图分别验证单选、Ctrl 非连续选择、Shift 连续选择；云盘三种视图提交相同的三个文件路径。
- 网格真实指针拖动：从空白区域框选两项，只选中相交文件。
- 云盘父级文件重命名：模拟接口记录的路径指向父目录中的目标文件，未误用当前子目录。
- 单讲 PPT 回归：单项调用只提交对应视频；批量调用只包含两个指定讲次；未扫描分类的全选意图仍正常工作。
- 完整套件 81 个文件、1258 项测试通过；TypeScript、ESLint、生产构建通过。

本报告的交互验证使用合成数据，不包含真实账号资料。真实服务的下载、上传及不同录播版本兼容性另行核验；这些测试结果不代表所有远端版本均已验收。
