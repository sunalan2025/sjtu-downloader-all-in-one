# 云盘文件管理与布局改造验证记录

日期：2026-10-26。

## 交付内容

- 云盘批量复制/移动、目标目录选择、应用内剪贴板、同名冲突策略与逐项结果。
- 异步服务端任务查询，支持多个提交批次累计后分组查询，避免超过接口的 200 项限制。
- 文件和文件夹上传/下载，保留目录层级、空文件夹；下载扫描失败时不提交不完整目录。
- 回收站浏览、恢复与单项永久删除确认；图片、音频、视频预览及网页端入口。
- 云盘主进程 API、前端页面和共享课程浏览器按职责拆分，保留原入口兼容导出。
- 课程页、云盘、资源库、传输中心、课表和设置页采用共享标题、间距与控件尺寸。
- 修复小字号工具未定义、`text-base` 与背景色命名冲突、动态按钮样式未生成、课表午间提示挤入单格等显示问题。
- 目录缓存按账号隔离并复用已准备的父目录；不再吞掉普通 HTTP 400 错误；同名冲突先确认目标确实是文件夹。
- 云盘 IPC 检查主窗口主 frame，校验路径与批量参数，切换账号停止后续提交，错误消息隐藏 URL token。
- 本地文件上传保留实际字节进度，不再以固定 100 字节作为完成大小；传输中心明确显示其暂不支持暂停/取消，避免提供无效按钮。

## 验证边界

没有对真实校园云盘执行写入，也没有生成或安装发行安装包。实际账号权限、回收站配置与校园部署的 SMH 接口版本需要真实环境联调。

异步复制/移动查询记录目前不跨页面会话或应用重启保存。本地文件直传暂不支持暂停、取消与跨重启恢复。分享、协作权限、版本历史及团队空间仍通过官方网页端处理。
