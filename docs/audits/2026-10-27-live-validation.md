## 本轮修复

1. **真实预览和下载失败**：`session.fetch(..., { redirect: 'manual' })` 在真实 302 响应时抛出 `Redirect was cancelled`。改用 SMH 的 `?info` JSON 接口获取签名地址，复用超时与错误脱敏，并拒绝非 HTTPS 或包含用户信息的直链。已完成真实预览及下载校验。
2. **勾选后快捷键失效**：原事件过滤器把复选框也视为文本输入，阻止 Ctrl+C/X/V、F2 等文件操作。现在仅在编辑控件及弹窗内保留原生按键行为；Ctrl+A 改为幂等全选。已在开发客户端复测。
3. **课表小窗口被长标题撑高**：截止事项标题同时使用 `flex` 与 `line-clamp-2`，导致截断失效。移除冲突布局，补充最小宽度与换行；每日默认展示两项，其余通过展开、收起查看。1024×680 下首屏重新可见课程格子，展开与收起均已验证。
4. **视频、PPT 分类图标不可见**：语义色 `sky`、`amber` 等覆盖 Tailwind 数字色阶，渐变起点样式缺失。将语义色置于 `DEFAULT`，保留原有色阶；实际图标背景恢复，编译 CSS 回归测试覆盖四种受影响色系。
5. **课程文件操作入口不明显**：列表中的下载／转存按钮改为常显，并统一课程行的基本高度。分栏视图补充选择课程提示，避免初始界面只有大片空白；已在真实客户端确认提示显示。
6. **Windows 保留端口使本地 Worker 无法启动**：实测系统保留区间包含原默认端口，固定端口返回 `EACCES`，系统分配端口可用。内置开发 Worker 在候选范围不可用时回退到系统分配的回环端口；守护进程报告真实监听端口，测试改用动态端口并在子进程提前退出时及时报错。未修改 Windows 端口保留配置。
7. **恢复后残留删除提示**：真实恢复成功后，主页面仍显示此前的“已删除”提示。回收站操作现在将成功消息同步到主页面，并刷新目录，避免关闭回收站后看到过时消息。该显示修复通过类型、Lint 和构建检查；未为复测提示再次删除真实目录。

接口依据：[SMH 获取文件下载链接和信息](https://intl.cloud.tencent.com/zh/document/product/1283/75432)、[Electron 手动重定向问题](https://github.com/electron/electron/issues/43715)。
