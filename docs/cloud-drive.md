# 交大云盘文件管理

## 已实现的操作

- 文件和文件夹：创建、重命名、批量复制、批量移动、删除；支持目标目录选择与根目录/上一级导航。
- 应用内剪贴板：复制、剪切、粘贴。快捷键为 Ctrl/Cmd+C、X、V、A，F2 重命名，Delete 打开删除确认。
- 三种独立保存偏好的视图：图标、列表、分栏。支持当前目录搜索、名称/大小/修改时间排序，文件夹始终优先。
- 上传本地文件或整个文件夹，保留层级与空目录；下载选中的文件或文件夹，加入传输中心并保留层级。
- 图片、音频、视频预览及文件属性；其他类型可转到官方网页端处理。
- 回收站分页浏览、恢复、单项永久删除确认。恢复采用自动重命名，原父目录不存在时回到根目录；服务端权限不足会显示错误。

## 操作反馈与冲突

复制/移动可选择“遇到同名则报错”或“自动重命名”。不会静默覆盖目标。批量操作逐项报告结果；服务器返回异步任务时显示“处理中”，每 3 秒查询一次，多个批次累计的任务按每组 200 个查询。查询失败后保留任务并允许重新查询，不会重新提交复制或移动。

复制/移动不是事务：某一项失败不会撤销之前成功的项目。网络中断时服务端可能已经执行，需刷新目录确认，客户端不自动重试变更请求。

上传文件遇到同名文件会保留原件，并在传输中心报告冲突。下载遇到本地同名文件、临时文件或已排队的相同目标会拒绝覆盖，需换一个保存目录。

删除操作是否进入回收站取决于服务端的回收站配置；删除确认中会说明该行为。永久删除另有二次确认。

## 数量与性能边界

| 场景 | 当前限制或处理方式 |
| --- | --- |
| 单次复制、移动、批量下载选择 | 最多 200 个顶层项目 |
| 文件夹上传/下载扫描 | 最多 10000 个项目、64 层深度 |
| 目录浏览 | 每次取 500 项，最多 200 页；失败时显示错误，不伪装为完整目录 |
| 界面渲染 | 每页最多 100 个项目；分栏只保留最近两级祖先和当前目录 |
| 本地文件夹扫描 | 异步读取文件信息与目录，避免同步递归阻塞主进程 |
| 本地文件直传云盘 | 同一提交批次最多 3 个并发上传 |

上传前先扫描本地目录，下载前先枚举完整远程目录；扫描失败不会把不完整文件清单交给下载队列。本地路径拒绝穿越、非法文件名与扫描树内的符号链接。

## 账号与进程边界

所有 `cloudpan:*` IPC 仅接受主窗口的主 frame 调用。路径、操作类型、冲突策略及任务 ID 在主进程再次校验。切换账号会清理目录缓存、前端状态与应用内剪贴板；旧批次停止后续提交，退出登录清除持久化 token。请求错误会隐藏 URL 中的 token。

已经发送到服务端的请求无法通过切换账号撤回。异步复制/移动的查询记录目前仅存在本次页面会话；关闭页面或重启应用后，需刷新相应目录确认结果。

## 当前未覆盖

本地文件/文件夹直传使用独立上传队列，尚未接入暂停、断点续传和跨重启恢复；课程资源的通用传输队列仍沿用原有控制能力。分享链接、多人协作权限、文件版本历史、团队空间管理仍由官方网页端提供。

本轮验证使用模拟 SMH 响应和合成界面数据，没有对真实校园云盘执行写入。校园部署的接口版本、回收站配置及具体账号权限仍需真实环境联调。

## 实现位置与协议依据

- `src/shared/cloud-drive.ts`：类型与输入约束。
- `src/main/cloudpan/`：会话凭据、文件 API、复制移动、回收站、COS 上传。
- `src/main/cloudpan-transfer.ts`：本地选择框、目录扫描、传输入队。
- `src/main/ipc/cloudpan-handlers.ts` / `src/preload/index.ts`：受限 IPC 与类型化桥接。
- `src/renderer/src/features/cloud-drive/`：目录、视图、操作状态及弹窗。
