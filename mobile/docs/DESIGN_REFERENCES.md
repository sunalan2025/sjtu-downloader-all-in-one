# 界面设计与许可

应用参考 [FlClash](https://github.com/chen08209/FlClash) 的中性分层表面、设置行、响应式导航与连续展开过渡，以及 [Material 3](https://m3.material.io/) 的颜色角色与自适应布局原则。

React、WAAPI 和 Android RemoteViews 实现由本项目维护，未复制 FlClash 或 prism_ui 的 Dart 代码。课程配色、桌面组件和按设备切换的导航动画使用本项目实现。

系统取色与主题生成使用 Apache-2.0 许可的 [Material Color Utilities](https://github.com/material-foundation/material-color-utilities)，许可随 APK 分发，见 `mobile/public/licenses/material-color-utilities.txt`。其他依赖遵循各自许可。
