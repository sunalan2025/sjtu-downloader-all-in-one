# SJTU Downloader Android 1.0.0

首个安卓正式版，支持手机和平板，保留已验证的课程资源下载、课程与考试、作业提交和评分、个人日程、分类提醒、后台同步及桌面日程组件。

- 首页按时间顺序加载近期安排，最多显示至下周日。
- 统一 Material You 明暗主题、浅色课程配色、自适应导航和展开/收起动画。
- 两款桌面组件支持准确时间、实时时间线与过去日程变灰；周末预览下周工作日，跨周日期范围分两行显示。
- 系统权限集中管理，未授权通知时不能开启提醒，后台同步独立设置。
- 移除未使用的测试通知入口与频道、旧版演示和试验目录。
- 使用不可调试的 Release 构建，应用名称移除 Beta，版本码提升至 10000。保留应用 ID 和升级签名，可覆盖同签名旧版。

发布流程要求通过完整界面回归、安卓原生测试、桌面时钟恢复及正式 APK 的启动和返回检查。测试与截图产物不进入正式 APK。
