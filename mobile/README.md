# SJTU Downloader for Android — v0.4.8 Beta

独立 Android 测试应用。代码位于 `feature/android-mvp`，不修改桌面版主线。

## 已接入（真正有代码实现）

- **同款图标**：Android 启动图标、桌面内 logo 全部由桌面版 `build/icon.png` 自动生成；不会使用 Capacitor 的默认机器人图标。
- **学期筛选**：读取 Canvas 返回的 `term.name`，按学期过滤、检索课程、查看课程文件。
- **批量下载**：多课程勾选、当前学期全选、单课程文件多选、全选当前文件类型、文档/视频文件/其他分类、点击下载后最多并行两项。课程扫描同时最多 3 项，最多单批次 1200 个文件。
- **存储归档**：App 私有外部下载目录 `Downloads/SJTU Downloader/<学期>/<课程名>/<文件>`，使用原生文件名清理并避免重名覆盖。当前无公共 Downloads 目录写入和 Android 系统下载管理器入口。
- **登录**：通过官方 Canvas SSO 进入 jAccount 手机网页，允许用户主动点击“交我办”链接跳转。额外的“交我办”按钮只会尝试触发**官方页面真实存在**的链接，不构造未经验证的 Deep Link，也不能保证校方 App 可以返回 WebView 会话。
- **日历**：Canvas `calendar_events` 先尝试，401/403 时退回已授权的 `users/self/upcoming_events` 及各课程 `assignments`。显示真实可访问活动与 DDL，明确说明部分数据可能不完整。没有完整正式教学课表与考试同步。
- **系统安全区**：Android 原生 edge-to-edge 和系统 Insets。
- **安装包身份**：独立 `me.hisunalan.sjtudownloader.beta` Beta 包名，可与旧 v0.1/v0.2 测试版并存。此分支以后由公开**测试用途专用**签名签署；绝不用于正式版发布，任何人都能复制此测试密钥，不能作为可信应用发布渠道。

## 2026-10-31 · Android 课程与导航交互改进（开发分支）

- **默认本学期**：课程页根据北京时间和 Canvas 的真实学期名称（如「2026-2027-1」「2026 年秋季」）自动筛选当前学期；用户可切换任意学期或显式选择「全部学期」。若学期名称无法识别，回退到最近的已分类学期。1 月仍归属上一年秋季学期。
- **选中即切换底栏**：勾选课程或文件时，底部四入口不再和额外固定批量按钮叠加，而是在同一位置显示单个宽幅「下载 N 门课程 / N 个文件」按钮。可在列表顶部取消选择恢复四入口。课程资源扫描过程中按钮禁用并显示进度文案。
- **动画与手势**：四入口的玻璃选中背景按位置滑动；主页面按导航方向左右位移并通过 clip-path 边缘遮罩显示，支持 WebView View Transitions 截图接续及旧内核的 CSS 回退。课程列表/详情和日历的周/日及日期切换也采用方向性揭示动画。尊重系统减少动态效果设置。
- **代码边界**：本次只修改 `mobile/src/` 前端；原生下载、认证与正式课表接口保持不变。功能改动首先由 `Android MVP Debug APK` CI 编译；实际点击手感、透明背景性能与 Canvas 真实学期命名仍需在真机验证。构建 Artifact 是调试 APK，不是正式发布的签名安装包。

## 未移植（不可误称已支持）

桌面版的旁听课程、好大学在线、Canvas 教师/PPT 双视角录播、HLS/FFmpeg 视频合并、PPT 图片转 PDF、交大云盘、可靠后台断点续传、多账号、私有中转服务、完整课表/考试仍需单独进行 Android 原生移植。页面里的“视频文件”分类仅限 Canvas Files API 已直接列出的常规视频文件，不会搜索课堂录播。

## 构建

要求 Node.js 22、JDK 21、Android SDK 35。图标从仓库根目录 `build/icon.png` 读取。

```bash
cd mobile
npm install
npm run build
npm run android:prepare
npm run android:icons
cd android
./gradlew assembleDebug
```

Android 工程和 native overlay 由 `android:prepare` 自动处理。也可进入 GitHub Actions 的 `Android MVP Debug APK` 流程查看已验证构建，下载 Artifact。

## 真机测试

1. 同时保留旧版（旧包名）与新版 Beta 应用，确认能独立安装启动，且图标与桌面版一致。
2. 登录 jAccount；验证“交我办”网页入口、App 打开及 SSO 返回。如果学校网页不展示快捷登录，记录具体页面地址和登录页截图，不要输入凭据到任何非官方域名。
3. 在“课程”中按学期筛选，分别测试单文件、多文件、多课程批量下载。检查私有目录层级（某些手机文件管理器不显示 Android/data，属于系统限制）。
4. 日历如遇 401 应显示授权提示或部分备用数据，不应直接把 401 当作整个日历崩溃。
5. 检查系统状态栏、挖孔与底部手势区适配、旋转屏幕、前后台切换。

当前版本的 Web 前端与原生代码由 CI 编译验证，但不等于使用交大账号完成真实授权及下载测试。只有在真机上验证后才能对这些功能做“可用”声明。

## v0.3.2 登录保持（安卓）

**正常关闭或杀死应用后重新打开，无需立即重新登录。** 登录成功后，App 将关键 Canvas / 正式课表会话 Cookie 加密保存于 Android 私有存储；AES-GCM 密钥由 Android Keystore 管理。再次启动前端会在原生网络请求前尝试恢复 Cookie，然后调用学校接口验证会话。恢复成功后自动加载课程；返回前台也会适时复查。没有保存 jAccount 账号密码，也不会把 Cookie 发送到开发者服务器。默认启用，无需“记住密码”复选框。

**边界**：会话是否继续有效由交大服务端决定；服务端过期/撤销或校园网不可达时无法绕过登录限制。清除应用数据、卸载重装将删除会话。明确点击“退出登录”并确认会同时清除 WebView Cookies 与加密的会话备份；不会在普通关闭应用时清除。

测试：`SessionCookieVaultTest` 使用虚构的本地会话 Cookie，在 Android 模拟器上检查加密、Vault 实例重建后恢复、退出后不可恢复。模拟器冒烟测试会 force-stop 和重新启动真实 APK。因为 CI 没有交大账号，真实服务器登录续期能力必须在已登录的实体手机上验证。

## v0.4 — Liquid Glass 风格与系统返回

- 全面改版为 iOS Liquid Glass 启发的**玻璃质感**：半透明层次、背景模糊、边缘高光、柔和渐变与浮动底部导航。实现为 Android/Chromium WebView 的 CSS 风格；并非苹果系统原生私有特效。
- 极简信息：主页只保留欢迎区、课程/下载数和**有内容时**才出现的今日日程；不再重复底部导航的快捷入口。课程列表只显示课程名，学期通过筛选器查看；下载页不再重复铺满统计卡。接口诊断折叠在日历下方，问题仍可排查。
- 动画：Tab 过渡淡入与位移、玻璃按钮按压回弹、选中态动态变化；Android 支持的设备上提供轻触选择反馈。尊重用户的 `prefers-reduced-motion` 与降低透明度/增加对比度设置。
- Android 系统返回：引入官方 Capacitor App 插件，优先退出课程文件详情，再返回首页；首页返回把应用最小化而不主动注销登录；登录中的原生 Dialog 由系统返回关闭。按 Android 系统能力启用预测性返回回调，避免网页级自制边缘滑动与系统手势冲突。
- 原生认证弹窗移除系统默认 Material Button 外观，统一圆角、轻玻璃按钮及浅色背景；交我办快捷登录和正式课表独立 SSO 改动继续保留。
- 正式课表需要从 `calendar.sjtu.edu.cn` 独立建立会话；Canvas 全部 200 不等于正式课表具备 Cookie。若学校需要同意授权，应通过可见的官方登录窗口完成；无法绕过官方流程。

## v0.4.2 · 课表自动更新、时间网格、悬浮顶栏与快捷唤起交我办

- 日历主页自动定位**北京时间的今天**，登录恢复时自动发起当月日历请求；回到日历页时自动检查是否超过 90 秒未同步。用户仍可以选其他日期/周。
- 复用桌面版的周课表信息结构：顶部一周 7 天切换；课程/活动按真实起止时间放入 **按小时的时间网格**（并排处理时间重叠）；**作业截止独立卡片放在课表上方**；无课时不展示整屏空网格。点击周导航中月份可展开月历。
- Canvas 登录后原生端静默尝试正式课表的独立 SSO；经真实 `/api/event/list` 校验成功后通过 `calendarSessionReady` 事件通知 Web UI 自动重新同步。未获授权时提供“连接正式课表”作为备用，不虚构数据或跳过学校审批。
- 顶部 SJTU Downloader 玻璃条浮在状态栏下方，有独立圆角与间距，不再从屏幕最顶端铺到玻璃背景。
- 登录点击后，Android 原生玻璃加载页遮住**仅用于生成校方动态 deep link 的官方 WebView**，自动选择 MOBILE 并点击官方交我办。动态 `jaccount://login?uuid=...` 仍必须由校方网页产生，不能安全地离线伪造；交我办 App 缺失/链接不可用或用户选择时，才显示正常网页登录作为兜底。返回应用后将自动检查 Canvas profile 以确认 SSO。
- 测试限制：CI 能检验 TypeScript、Android 原生编译和模拟器运行，不具备真实交我办 App 和校方个人账号，因此不能承诺所有机型的 App 唤起/回跳或正式课表授权必然成功。

## 2026-10-31 · v0.4.4 布局修正

- **切页动画**：消除 View Transition 结束后重新播放 CSS 进场动画的双重触发。快速点击其他 Tab 时取消前一个过渡；为不支持新 API 的 WebView 保留轻量左右遮罩，减少过渡模糊与闪白。
- **周课表**：不再把每一天的事件简单依次堆叠。使用一条共享的北京时间轴和七列绝对定位课程卡片；同一时间对应同一水平线。日期头、全天作业、小时网格在同一个横向滚动容器中，重叠课程按列排列，移动端支持滑动。
- **顶部白条**：统一 Android Window / WebView、HTML theme-color 和页面背景色，去掉多组重复顶部栏样式，并仅为系统状态栏保留一次安全距离。仍需在有刘海/挖孔的真机上确认最终外观。
- **回归测试重点**：连续快速点击四个 Tab；切换课程列表/详情；在周视图跨周滚动并观察同一小时是否对齐；检查启动后状态栏、向下滚动时悬浮品牌栏与底部系统手势区是否出现白色间隙。

## 2026-10-31 · v0.4.7 操作体验更新

- **日历三列**：所有手机上的周时间表均显示选中日期的前一天、当天和后一天，选中日期始终居中；上方日期条、月历、左右箭头、手势滑动会一起更新中心日期。跨周时也保持三列，时间轴按所见日期计算。
- **个人日程**：首页“近期安排”汇总已同步的学校课表/作业及本地个人日程，允许新建、编辑、删除；可设日期、起止时间、全天、备注，保存在 WebView 本地存储。日历上方“+”可添加；个人课程卡片点按可编辑。自定义日程仅保存在本机，不会写回学校系统，卸载应用可能丢失。
- **文件长按批量选择**：文件列表常态不显示选择框。长按任一可下载文件约 380 毫秒进入选择模式，继续上下拖动跨越文件行进行范围多选。显示选择框后支持单项切换、全选、完成，选中项目通过底部下载按钮执行。
- **下载历史**：移除“找回旧版文件”；下载页提供“清除历史”，只清除不在进行中的记录，不删除公共 Downloads 的实际文件。
- **动画**：主导航与课程/日历子页面使用同一组缓动节奏（短位移、弱透明、短距离遮罩，末端逐渐减速）；导航指示器使用微小弹性，无旧页面截图残影。首次加载不执行子页面切换动效。
- 测试提醒：Android WebView 不同机型的长按与触控取消行为会有差异；三列布局与动效已通过静态和 CI 编译检查，但仍需用户真机验证。
